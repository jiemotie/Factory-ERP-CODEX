# Web 管理端

Web 管理端用于后台管理、主数据维护、订单录入、工序跟踪和报表查看。

## 当前实现状态

当前已实现一个无构建步骤的表格化管理端原型：

- 入口：启动后端后访问 `http://localhost:3000/` 或 `/web`。
- 登录：使用后端开发账号 `admin` / `admin123`。
- 数据形态：暂不接入真实数据库，页面只通过统一后端 API 读取和写入原型数据，并以表格形式展示、录入和流转。
- 已接入模块：用户/角色/权限、材料入库、库存流水、库存余额、订单录入、从订单生成工序任务、工序任务、报表分析和审计日志。
- 表格能力：每张表支持关键字筛选、每页条数切换、上一页/下一页分页和 CSV 导出，便于当前“表格化数据”阶段快速核对数据。
- 技术方式：原生 HTML、CSS、JavaScript，无前端依赖，便于后续迁移到 React 或 Vue。

## 数据访问原则

- 只能通过 `backend/` 暴露的统一 API 读写业务数据。
- 不直接连接数据库。
- 不在浏览器本地持久化权威业务状态；`sessionStorage` 仅保存当前开发登录态，后端数据始终是唯一权威来源。

## 建议技术栈

当前原型保留 `src/` 作为前端工程入口。后续如果需要更复杂的交互、路由、权限菜单和组件化表格，可迁移为 React 或 Vue，但仍应沿用同一套 `/api/v1` 后端接口。
