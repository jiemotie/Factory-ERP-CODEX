# OpenAPI 契约

后端提供机器可读的 OpenAPI JSON 契约，供 Web、Windows 桌面端和 Android 移动端统一生成 API 客户端或进行接口联调。

## 获取方式

启动后端后访问：

```http
GET /api/v1/openapi.json
```

该接口不需要登录，便于开发工具读取接口定义；业务接口仍按各模块权限进行后端校验。

## 当前覆盖范围

OpenAPI 契约已覆盖：

- 身份认证、用户、角色、权限接口
- 材料入库、库存流水、库存余额接口
- 订单录入和订单状态流转接口
- 工艺路线、工序任务和工序状态流转接口
- 入库统计、订单进度、工序产能、良率、库存余额报表接口

## 后续计划
