# Priority Modules

## 1. 用户、角色、权限基础模块

目标：建立统一身份认证和授权模型。

核心能力：

- 用户账号、密码或第三方登录绑定
- 角色管理
- 权限点管理
- 用户-角色关联
- 角色-权限关联
- 登录、刷新 Token、退出登录
- 操作审计

## 2. 材料入库模块

目标：管理材料采购到货、质检、入库和库存变更。

核心能力：

- 入库单创建与审核
- 材料明细、批次、数量、单位、供应商记录
- 质检结果登记
- 入库确认后写入库存流水
- 入库单状态跟踪

## 3. 订单录入模块

目标：统一记录客户订单和生产需求。

核心能力：

- 订单创建、编辑、取消、审核
- 客户、产品、数量、交期、备注记录
- 订单状态流转
- 与工序流转模块建立生产任务关系

## 4. 工序流转模块

目标：跟踪订单在生产工序中的流转状态。

核心能力：

- 工艺路线维护
- 工序任务生成
- 工序开工、完工、暂停、返工
- 人员、设备、时间、产量和不良数记录
- 工序状态看板

## 5. 报表分析模块

目标：基于统一后端数据输出管理报表。

核心能力：

- 入库统计
- 订单进度统计
- 工序产能与良率分析
- 库存变动分析
- 可按时间、客户、产品、工序、人员等维度筛选
