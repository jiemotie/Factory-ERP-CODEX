# 当前任务状态

## 总体判断

当前项目已从“项目骨架”进入“后端 API 原型增强”阶段。后端仍是唯一数据源，Web、Windows 桌面端和 Android 移动端尚未实现业务界面，后续应继续优先完善后端业务闭环与接口契约，再推进多端接入。

## 已完成

- 多端目录结构：`backend/`、`web/`、`desktop/`、`mobile/`、`docs/`。
- 后端无外部依赖 API 原型：统一 `/api/v1` 路由、JSON 请求解析、错误响应、跨域响应头。
- 身份模块：登录、登出、用户、角色、权限基础接口。
- 材料入库模块：入库单创建、审核、确认入库、库存流水、库存余额汇总。
- 订单录入模块：订单创建、查询、更新、审核、取消。
- 工序流转模块：工艺路线、工序任务、开工、完工、返工。
- 报表分析模块：入库统计、订单进度、工序产能、良率分析、库存余额报表。
- OpenAPI 契约：通过 `GET /api/v1/openapi.json` 输出机器可读接口定义。
- 可选 JSON 文件持久化：通过 `ERP_DATA_FILE` 指定本地数据文件。
- 自动化测试：覆盖认证、入库、库存、订单、工序、报表和持久化。

## 进行中

- 将内存/JSON 文件数据源抽象为后续数据库仓储接口。
- 扩展状态机约束，例如订单、工序、入库单之间的联动校验。
- 继续细化 OpenAPI 请求体、响应体和错误示例，便于 Web、桌面端和移动端生成客户端。

## 待开始

- Web 管理端首屏、登录页和 API 调用封装。
- Windows 桌面端或 Electron/Avalonia 原型。
- Android 移动端扫码入库与工序报工原型。
- 数据库迁移脚本、真实密码哈希、生产级 Token 和权限策略。

## 冲突分析

当前本地工作区无合并冲突标记。由于当前环境访问远端仓库时返回 `CONNECT tunnel failed, response 403`，无法在本地完成真实远端 rebase/merge；创建 PR 后应由平台基于最新主干自动检测冲突。如出现冲突，优先保留已合并的目录结构与后端 API 约定，再叠加本分支新增的库存余额和状态文档改动。
